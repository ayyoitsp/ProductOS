---
title: User account manager
---
The subsystem that answers *who is in this workspace, and in what capacity*. It holds
the roster: who has an account, who has been invited and not yet accepted, what each
person is allowed to do, and who has been removed.

Anything user-facing about membership is somebody else's — the invite form, the message
an admin reads, the accept page. This side only promises what is true of the roster once
it has been asked to change it, and what a caller may rely on when it answers.
