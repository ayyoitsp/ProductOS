# ProductOS — Usage

> **Retired 2026-08-03, pending rewrite.**

This document described usage under the git-native design — a repo checked out locally, a product-truth
site on `localhost:7878`, and Claude Code skills as a co-equal authoring surface. That architecture is
retired.

ProductOS is now a **standalone hosted service** with a product app as the authoring surface, an MCP
bridge for agents, and markdown as an export rather than the authority.

It will be rewritten once v0.1 exists and the flows are real. Writing it now would document a product
that doesn't exist yet — and inventing usage docs ahead of the product is how docs and reality drift
apart, which is the problem this project exists to solve.
